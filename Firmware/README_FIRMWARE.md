# 超声追踪小车固件

本程序用于 STC8H8K64U 打狗棒、TB6612、HC-SR04 与 HS96L03W2C03 OLED。
需求范围：前方距离跟随；不包含左右搜索、遥控、编码器闭环或按键启停。

## 打开与编译

打开本目录 car.uvproj。原有 7 个 C 文件已全部在工程中，头文件搜索路径保持 Config、Drivers、App。
Config/STC8H.H 从本机已安装的 STC 芯片包复制，队友无需额外寻找这个头文件。
STC-ISP 的 IRC 运行频率必须设为 11.0592MHz；程序取消额外系统分频。

2026-10-12 初次整合版本的所有 C 文件已编译；链接报告 code=3479、data=70.1、xdata=0。
本机 Keil 评估版在链接时报 L250（2KB 代码大小限制），不是 STC 芯片 Flash 不够。
因此没有生成整合版 HEX。用户随后要求自行编译；最后的启动计时溢出修正尚未重新编译。
请使用支持本工程大小的合法 C51 环境完成 Rebuild，确认成功后再烧录 Objects/car.hex。
原来的 Objects/car.hex 是 10月9日面包板程序，已改名 Objects/OLD_BENCH_car_20261009.hex，不能把它当作新固件。

## 默认行为与参数

程序上电先保持电机停止，显示初始化结束后再等待约2秒；之后至少连续2次有效且在跟随范围内的测量才允许运动。
静止时距离大于280mm前进，小于220mm后退；行进中回到250mm时停止，形成回差。
超过1500mm、无回波、Echo异常高或距离超出20~4000mm，均停止并重新累计有效测量次数。
无回波等待上限60ms，Echo高电平等待上限40ms；两次测量间隔至少200ms。
测距为有超时的轮询，并非中断捕获；轮询时T0中断和硬件PWM仍运行。
移动占空比默认30~55%，后退上限35%；每20ms最多调整5个百分点。主循环阻塞时斜坡更新可能更慢。
换向先输出0并停顿至少100ms，再逐步加速。
没有轮速传感器，占空比不等于实际速度；左右轮差异和最低起转占空比需实物调整。
所有默认值集中在 Config/config.h。速度与1500mm最大跟随范围是初始调试值，不是课程已规定参数。

## 引脚与资源

|功能|引脚/资源|
|---|---|
|A路PWM|P2.0 / PWMB模块PWM5|
|B路PWM|P2.1 / PWMB模块PWM6|
|AIN1 / AIN2|P1.0 / P1.1|
|BIN1 / BIN2|P1.3 / P1.4|
|超声Trig / Echo|P3.4 / P3.5|
|OLED SCL / SDA|P2.2 / P2.3，开漏软件I2C|
|T0|1T、模式0的16位自动重装，约1ms系统节拍|
|T1|12T、模式1，回波脉宽计时|
|PWM周期|1000个系统时钟，约11.0592kHz，两路分别调占空比|
|STBY|原PCB接高电平，无软件控制引脚|

只开启PWM5/6输出；没有开启P2.2/3的PWM7/8。不再使用P2.0闪灯测试。
T0只由timebase.c管理，T1只由ultrasonic.c管理，PWMB只由motor.c管理。
main.c开中断后才调用毫秒延时。不要把旧main中的EA=0、T0阻塞延时再复制回来。
程序拥有整个PWMB模块，并关闭PWMA输出；以后新增PWM使用者必须重新协调。

## 文件职责

- Config/config.h：时钟假设、阈值、方向反转、功能开关和速度参数。
- Config/board.h：统一引脚和基本类型，包含本地STC8H.H。
- Drivers/timebase.c：T0节拍、原子读时间、短延时。
- Drivers/ultrasonic.c：保留已跑通的测距换算，所有等待有超时。
- Drivers/motor.c：PWM5/6、方向输出、占空比斜坡、换向间隔。
- Drivers/oled.c：沿用已点亮的屏幕初始化、ACK检测与0x3C/0x3D探测，扩充状态字符。
- App/car.c：采样调度、有效性判断、回差跟随策略。
- App/display.c：距离、控制状态、两路当前指令占空比；每次主循环最多刷新一行。
- main.c：初始化与调用各任务。

OLED失败时停止刷新，不会阻止测距/电机控制；修复屏幕接线后重新上电。
屏幕FORWARD/REVERSE表示控制要求，底行A/B值表示正在输出的逻辑占空比，换向停顿期间可为0。

## 首次上板

1. 首先备份并保存当前Keil窗口，外部文件变更提示请选择重新加载磁盘文件，避免旧编辑缓冲区覆盖新代码。
2. 可先将 MOTOR_ENABLE 改为0，只验证距离与状态；OLED_ENABLE 默认1。
3. 测试电机时架空车轮，确认TB6612电源、公共地、STBY与电机接线。电机VM用合适的电机电源；核心板USB与外部VCC不要双重供电。
4. 将MOTOR_ENABLE改回1，重新编译烧录。默认上电无需按钮即可自动跟随。
5. 书本放在约40cm应要求前进，25cm停止，15cm后退，移开目标应停车；该程序不具备判断目标左右位置的能力。
6. 如果某个轮子方向反了，修改MOTOR_A_INVERT或MOTOR_B_INVERT（0/1），然后重新编译。A/B并未预设对应实际左/右轮。
7. 验证断开Echo、无目标和长时间运行，确认不会维持旧距离继续驱动。最后再落地低速试验并调参数。

OLED电压备注：保留用户已点亮模块的程序配置。用户采用老师确认的直连接法；此前找到的同型号手册电压表与此存在差异。此次仅修改软件，没有测量模块电压或证明其长期5V兼容性。
